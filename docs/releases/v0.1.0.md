**Minecraft 26.3** · **Fabric Loader 0.19.5+** · **Fabric API** · **Java 25** · **Vulkan**

### 🇬🇧 English

First public release of Basalt, an all-in-one performance mod built around the Vulkan renderer.

- 🎨 **Rendering:** 16-byte chunk vertices, per-direction face culling, cached draw lists, GPU Hi-Z occlusion
  culling of chunk sections, culling of entities and block entities hidden behind walls, faster entity/item models,
  sign text layout cache, faster biome tint blending.
- 🌍 **World generation:** the FEATURES step runs in parallel on its own priority thread pool; optional native
  (Rust) terrain noise, verified bit-for-bit against Java.
- ⚡ **Server:** faster collisions, entity lookups, villager POI searches, mob AI, random ticks and chunk level queries.
- 🧠 **Memory:** compact block state tables, shared block shape data, lightweight per-section threading check.

Every feature can be switched off in `config/basalt.properties` or in *Options → Video Settings*.

**Install:** put `basalt-0.1.0.jar` and Fabric API into your `mods` folder.

### 🇷🇺 Русский

Первый публичный релиз Basalt — мода на производительность «всё в одном», построенного вокруг Vulkan-рендерера.

- 🎨 **Рендер:** 16-байтовые вершины чанков, отсечение граней по направлению, кэш списков отрисовки, Hi-Z
  окклюзионный куллинг секций чанков на видеокарте, скрытие сущностей и блок-сущностей за стенами, быстрые модели
  мобов и предметов, кэш раскладки текста табличек, быстрое смешивание цветов биомов.
- 🌍 **Генерация мира:** этап FEATURES выполняется параллельно в собственном пуле потоков с приоритетами;
  опциональный нативный (Rust) шум рельефа, побитово сверяемый с Java.
- ⚡ **Сервер:** быстрее столкновения, поиск сущностей, поиск точек интереса жителей, ИИ мобов, случайные тики и
  запросы уровня чанков.
- 🧠 **Память:** компактные таблицы состояний блоков, общие данные форм блоков, лёгкая проверка многопоточности в секциях.

Любую функцию можно выключить в `config/basalt.properties` или в *Настройки → Настройки графики*.

**Установка:** положите `basalt-0.1.0.jar` и Fabric API в папку `mods`.
